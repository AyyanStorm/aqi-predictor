## 🏗️ Decision Making

### Major Decisions (Architecture, Dependencies, Roadmap)
- **Owner:** AYYAN
- **Process:**
  1. Discuss in Discord #aqi-predictor
  2. Document in DECISION_LOG.md
  3. Create GitHub issue if needed
  4. Implement or delegate
- **Record:** See DECISION_LOG.md

### Code Review & Merges
- **Process:**
  1. Create PR from feature branch
  2. Link to issue
  3. Run CI/CD checks (all must pass)
  4. Self-review or request review
  5. Squash-merge to main

### Release Management
- **Frequency:** Every 1-2 weeks (as needed)
- **Process:**
  1. Update CHANGELOG.md
  2. Bump version in pyproject.toml
  3. Tag release on GitHub
  4. Deploy to Render.com
- **Owner:** AYYAN
