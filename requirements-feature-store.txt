# requirements-feature-store.txt — Hopsworks feature-store pipeline env.
#
# Deliberately SEPARATE from requirements.txt. hopsworks pins
#   protobuf<5.0.0,>=4.25.4   and   pandas<2.4.0
# which HARD-CONFLICT with the dashboard/training env:
#   keras requires protobuf>=5.26.1   (no overlap -> pip cannot resolve)
#   the venv has pandas 3.x            (hopsworks needs <2.4)
# They can never live in one environment, so the feature-pipeline scripts
# (hourly_ingest.py, historical_backfill.py) run in their own venv.
#
# IMPORTANT — hopsworks requires Python >=3.10,<3.14.
#   Python 3.14 is NOT supported yet (pip rejects 5.x and falls back to
#   ancient sdists that crash on modern Python — the confusing "No module
#   named 'imp'" error). Use Python 3.12 or 3.13 for this venv.
#
# NOTE — hopsworks also pulls `pyjks` -> `twofish`, and twofish ships NO
#   wheels (source only, needs a C compiler). On Linux CI (gcc present)
#   it builds fine. On Windows without MSVC build tools it fails — use
#   the --no-deps workaround at the bottom of this file instead.
#
# Linux CI (GitHub Actions feature_pipeline.yml, has gcc):
#   pip install -r requirements-feature-store.txt
